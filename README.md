# SuperWay Website

Premium, conversion-first landing site for SuperWay Cleaning Services.

## Local development

```bash
pnpm install
pnpm dev
```

## Verification

```bash
pnpm lint
pnpm test
pnpm build
pnpm test:e2e
```
